# Proposta de CRUD — Marketplace inspirado no Mercado Livre

A ideia do projeto é desenvolver um sistema de marketplace inspirado no modelo do Mercado Livre, permitindo que usuários possam cadastrar, visualizar, editar e excluir produtos de forma simples e organizada. O sistema terá como objetivo simular as principais funcionalidades de uma plataforma de comércio eletrônico, proporcionando uma experiência completa tanto para quem deseja vender quanto para quem deseja comprar
